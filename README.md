# Cybersecurity Topics Documentation

## 1. React Website Current 2026 Attacks
Overview of modern security threats targeting React-based web applications in 2026, including XSS, supply-chain attacks, dependency vulnerabilities, and insecure API integrations.

## 2. FastAPI Attack & Vulnerabilities
Discussion of common security issues in FastAPI applications such as improper authentication, insecure endpoints, injection attacks, and lack of rate limiting.

## 3. Google Cloud Security Issues
Security risks related to cloud environments including misconfigured storage buckets, weak IAM permissions, exposed APIs, and poor monitoring in Google Cloud.

## 4. Windows-Based Vulnerabilities
Common vulnerabilities affecting Windows systems including privilege escalation, outdated patches, SMB attacks, and insecure services.

## 5. Misconfiguration Request Attack
Explanation of attacks that exploit server or application misconfigurations such as exposed admin panels, default credentials, and insecure headers.

## 6. Cookie Hijacking / Session Stealing
Description of how attackers steal session cookies to impersonate users, including methods like XSS, packet sniffing, and session fixation.

### Prevention Methods
- Use HTTPS
- Secure and HttpOnly cookie flags
- Session expiration policies
- Token-based authentication

## 7. SQL Evil Query Attack
Explanation of SQL Injection attacks where malicious SQL queries are inserted into application inputs to access or manipulate database data.

## 8. Database Manipulation & Firewall Bypass
Techniques attackers use to modify databases or bypass firewall protections through injection, tunneling, or misconfigured rules.

## 9. What is Darknet
Introduction to the Darknet — a part of the internet not indexed by search engines and accessible through special networks like Tor, used for anonymity.

## 10. VPN Working
Explanation of how Virtual Private Networks work, including encryption tunnels, IP masking, and secure communication between users and servers.
