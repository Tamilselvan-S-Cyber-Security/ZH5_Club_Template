# Slide 2 – Title & Abstract

## Title
**Real-Time Log Monitoring and Intrusion Detection using Wolf Security Scanner**

## Abstract
Organizations generate massive amounts of system and network logs every second. 
Manually monitoring these logs to detect security threats is difficult and inefficient. 

The **Wolf Security Scanner** is designed to analyze logs in real time and identify suspicious activities using automated detection techniques. 

This system helps security teams quickly detect cyber attacks, abnormal behaviors, and system failures. It improves security monitoring by providing alerts, visualization, and simplified investigation tools.
